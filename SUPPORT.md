# Support

- **Questions, bugs and ideas:** open an issue in the project's repository.
  Please include the version, what you expected, what happened, and the
  relevant output — with tokens and keys removed.
- **Security problems:** report them privately, as [SECURITY.md](SECURITY.md)
  describes. Not in a public issue.
- **Documentation:** each project's README links to its documentation.

Issues opened here are carried into the maintainers' private Forgejo by
[forgejo-github-bridge](https://github.com/metapatrol/forgejo-github-bridge),
and their replies come back here, posted by a bot account that names who wrote
them. There is no other support channel and no guaranteed response time.
